VERSION 1.4.0 · WINDOWS x64

Feel your PC games on your handheld.

HapticBridge brings DualSense haptics from compatible Windows games to supported Android controllers, including compatible Razer Kishi models. Pair through Apollo and Artemis, then test haptics before launching a game.

See how to set it up

Get connected

  1. Check the PC

    Use Check PC setup to identify required tools. Start Apollo from HapticBridge to apply DualShock 4 emulation.

  2. Pair Artemis

    Add the PC address shown in HapticBridge while on the same network. Enter the phone’s PIN under Pair or manage devices.

  3. Try haptics

    Start a stream and turn on Audio to Haptics on the phone. Enable haptics in HapticBridge and run the built-in test.

Game and controller support varies. Controller + Audio with a blank display requires a compatible Apollo build.

What’s new in 1.4.0

Automatic DualShock 4 setup, improved local Apollo management, and automatic volume for the virtual DualSense audio endpoint.

Windows 11 x64 is the primary target. Windows 10 22H2 x64 has a separate compatibility test build.
